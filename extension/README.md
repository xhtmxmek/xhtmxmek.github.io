# Vimeo 실시간 자막 번역 (OpenAI) — 크롬 확장(MV3)

Vimeo 페이지에서 **VTT 자막을 가져와** OpenAI API로 번역하고, **영상 타임라인에 맞춰** 화면 하단(오버레이)에 번역 자막을 표시합니다.

## 설치(개발자 모드)

1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** ON
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 레포의 `extension/` 폴더 선택

## 사용 방법

1. Vimeo 영상 페이지로 이동
2. 확장 아이콘 클릭 → **OpenAI API Key** 입력 → **저장**
3. 페이지 우측 하단에 뜨는 **번역 시작** 버튼 클릭
4. 번역 진행률이 표시되고, 완료/진행 중에도 타임라인에 맞춰 자막이 표시됩니다.

## 설정

- **모델**: 기본값 `gpt-4o-mini`
- **번역 언어**: 기본값 `ko`
- **배치 크기**: 한 번에 번역할 cue 수(기본 18)

## 동작 방식(중요)

- 이 확장은 DevTools 네트워크 탭을 “훔쳐보는” 방식이 아니라,
  **페이지 내의 `track`(subtitles/captions) 또는 HTML 내 `.vtt` URL**을 찾아 VTT를 가져옵니다.
- 번역은 **배치 단위**로 진행되며, 완료된 cue부터 바로 표시됩니다.
- 번역 결과는 `chrome.storage.local`에 **VTT URL + 언어 + 모델** 조합으로 캐시합니다.

## 제한 사항 / 안 될 때 체크리스트

- **영상에 자막(VTT)이 실제로 존재해야** 합니다. (자막이 없으면 잡을 수 없습니다)
- Vimeo가 **iframe(다른 도메인) 안에서 재생**되는 구조면, 콘텐츠 스크립트가 접근 못 할 수 있습니다.
- VTT URL이 CORS로 막혀 있으면 VTT 다운로드가 실패할 수 있습니다.
- OpenAI API Key를 확장에 저장하는 것은 **프로토타입 용도**입니다. 실서비스는 **서버 프록시**를 권장합니다.
